WEBSITE ANNIVERSARY THEATER — PETUNJUK EDIT

1. Buka index.html di browser untuk melihat website.
2. Untuk mengedit tulisan, buka index.html dengan VS Code, Notepad++, atau Notepad.
3. Foto berada di folder assets. Jangan ubah nama file foto kecuali kamu juga mengganti referensinya di index.html.
4. Musik: karena browser membatasi autoplay dan audio berhak cipta tidak disertakan, tombol musik membuka hasil pencarian YouTube untuk “Paramore - The Only Exception”. Pengunjung bisa menekan Play di YouTube. Untuk pengalaman paling konsisten, ganti tautan pencarian di fungsi toggleMusic() dengan tautan video resmi yang kamu pilih.
5. Kirim seluruh folder ini dalam ZIP, atau unggah ke layanan hosting statis (misalnya GitHub Pages/Netlify) agar pacarmu dapat membuka lewat tautan. File HTML lokal tidak otomatis menjadi tautan publik.

Bagian utama yang bisa kamu edit:
- Slide 1: Greeting
- Slide 2: Ucapan terima kasih
- Slide 3: Permintaan maaf
- Slide 4: Evaluasi hubungan
- Slide 5: Closing dan harapan
